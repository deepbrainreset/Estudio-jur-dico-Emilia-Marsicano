# Estudio Jurídico Emilia Marsicano

Professional legal-services website built as part of the Deep Brain Reset web portfolio.

## Overview

The project combines responsive React development with service-oriented integrations intended for a real professional-services workflow, including payment and scheduling capabilities.

## Tech Stack

- React 19
- TypeScript
- Node.js / Express
- Vite
- Tailwind CSS
- Motion
- Google APIs integration capability
- Mercado Pago integration capability
- PayPal integration capability
- Google Gemini integration capability

## Development Approach

The project was developed using an AI-assisted engineering workflow. AI coding tools accelerate implementation, debugging, refactoring, and iteration, while product direction, architecture, integration, testing, and final delivery remain under human supervision.

## Local Development

```bash
npm install
npm run dev
```

Type checking:

```bash
npm run lint
```

Production build:

```bash
npm run build
```

## Security

Runtime credentials and local environment files must remain outside version control. Public configuration examples should contain placeholders only.
